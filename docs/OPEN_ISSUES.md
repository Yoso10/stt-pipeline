# Open issues register

How to use: every DEFAULT or OPEN item of the PRD is tracked here. The agent never changes a DEFAULT or an OPEN item on its own. When real run results exist (reports, WER, rejected-sample statistics, timings) the agent shows the evidence, proposes a change, records the outcome here after the owner decides, and only then applies it.
Columns: the issue, the current stance (DEFAULT, DECIDED, open), and what evidence settles it.
